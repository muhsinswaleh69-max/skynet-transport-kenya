# skynet-transport-kenya
Kenya bus booking system. Clients book online, get unique code SKY-XXXX to board, pay via MPESA. 3 portals: Client seat map + booking, Company QR verification + sales reports, Super Admin 10% commission dashboard. Solves office queues. Built Next.js. Routes: Kakamega-Nairobi, Mumias, Kisumu, Mombasa
